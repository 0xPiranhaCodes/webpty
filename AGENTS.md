# Agent guide for webpty

Any code or behavior change follows the three-role workflow in
[.agents/skills/contribute/SKILL.md](.agents/skills/contribute/SKILL.md):
architect designs, staff-engineer implements, sdet proves. Start there.

Human contributor guidance is in [CONTRIBUTING.md](CONTRIBUTING.md); the
canonical product constraints are in
[docs/specs/product.md](docs/specs/product.md); `make check` and `make e2e`
are the gates CI runs.
