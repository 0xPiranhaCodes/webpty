# Security Policy

## Supported versions

Security fixes are provided for the current development branch and the latest
published release.

| Version | Supported |
| --- | --- |
| `main` | Yes |
| Latest release | Yes |
| Older releases | No |

## Reporting a vulnerability

Do not disclose suspected vulnerabilities in a public issue, discussion, pull
request, terminal recording, or log.

Privately email [satheesh.101097@gmail.com](mailto:satheesh.101097@gmail.com).
This email address is the authoritative vulnerability-reporting channel.
Include the affected version, impact, reproduction steps or a proof of concept,
and any suggested mitigation. Redact credentials, capability links, and
unrelated terminal contents.

Reports and follow-up are handled on a best-effort basis; you will receive an
acknowledgement when the report has been reviewed.
